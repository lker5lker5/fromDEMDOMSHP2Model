📖 使用说明

地灾单点制图 Web 应用 (Cesium版) — 上传 DEM/DOM/SHP 数据，生成交互式 3D 地形与灾害边界叠加图。

  • 上传数据：分别选择 DEM(.tif)、DOM(.tif) 和 SHP(.zip) 文件，勾选要展示的字段后点「开始处理」
  • 参数调整：在左侧面板调整标题、地形、光照、视角、样式等参数
  • 应用：修改参数后点「应用」或按 Ctrl+Enter 刷新 3D 视图
  • 重置：恢复上传时的默认参数
  • SHP 字段：选择 SHP 文件后，在文件选择器下方勾选要展示的属性字段，再点「开始处理」
  • 下载 PNG：选择分辨率和 DPI 后下载静态图片
  • 下载 HTML：下载可离线打开的交互式 3D 文件
  • 交互操作：鼠标拖拽旋转、滚轮缩放、右键平移
