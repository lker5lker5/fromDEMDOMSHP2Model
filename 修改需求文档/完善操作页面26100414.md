# 地灾单点制图 Web 应用 — 增量修改规格（v2）

> 本文档是对 v1 规格说明书的**增量修改**。未在本文件提到的内容，仍按 v1 规格执行。
> 请将本文件与 v1 规格一起交给 Claude CLI，作为完整开发指令。

---

## 1. 修改目标

1. **页面布局重排**：左侧为操作与参数区，右侧为结果展示与下载区
2. **制图参数面板化**：所有可调参数在左侧面板分组展示，供用户自主调整
3. **SHP 字段勾选**：用户上传 SHP 后，可自主勾选要展示的属性字段
4. **结果展示与下载分离**：右侧上方为 3D 视图，下方为下载区

### 2.2 布局规则

- 使用 **CSS Grid**：`grid-template-columns: 340px 1fr`
- 左侧面板：`overflow-y: auto`，高度 `calc(100vh - 60px)`
- 右侧：`display: flex; flex-direction: column`，3D 视图 `flex: 1`，下载区固定高度
- **不用任何前端框架**，纯 HTML + CSS Grid + vanilla JS
- **响应式**：宽度 < 900px 时改为上下布局（左侧面板折叠到顶部，可抽屉式展开）

### 2.3 顶部栏

- 高度 60px，白底 + 底部细线
- 左侧：应用标题（如“地灾单点制图 — 3D 可视化”）
- 右侧：帮助按钮（点击弹出使用说明）

## 3. 制图参数面板（替换 v1 第 5.1 节参数部分）

左侧“3. 制图参数”区域，用 **可折叠分组（`<details>` 标签）** 组织，默认全部展开。每组内滑块右侧实时显示当前数值，拖动时只更新数字，点“应用”后才刷新 3D。

### 3.1 分组 1：标题

| 参数 | 控件 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `title` | `<input type="text">` | “DOM + DEM + SHP to 3D view Model” | 图标题 |
| `title_fontsize` | 滑块 10–24 | 16 | 标题字号 |

### 3.2 分组 2：地形

| 参数 | 控件 | 范围 | 默认 | 步长 |
| :--- | :--- | :--- | :--- | :--- |
| `vert_exag` | 滑块 | 0.1 – 3.0 | 0.8 | 0.1 |
| `z_exag_visual` | 滑块 | 0.5 – 3.0 | 1.2 | 0.1 |
| `max_size` | 滑块 | 200 – 1200 | 600 | 100 |

说明：`max_size` 改大后，3D 视图面片更多、细节更好，但渲染变慢。滑块旁提示“数值越大越慢”。

### 3.3 分组 3：光照

| 参数 | 控件 | 范围 | 默认 | 步长 |
| :--- | :--- | :--- | :--- | :--- |
| `azdeg` | 滑块 | 0 – 360 | 315 | 5 |
| `altdeg` | 滑块 | 5 – 90 | 45 | 5 |
| `hillshade_mix` | 滑块 | 0 – 1.0 | 0.45 | 0.05 |

`hillshade_mix=0` 表示完全不叠阴影，`=1.0` 表示完全用阴影调制亮度。

### 3.4 分组 4：视角

| 参数 | 控件 | 范围 | 默认 | 步长 |
| :--- | :--- | :--- | :--- | :--- |
| `view_elev` | 滑块 | 0 – 89 | 58 | 1 |
| `view_azim` | 滑块 | -180 – 180 | -55 | 5 |
| `view_distance` | 滑块 | 1.5 – 4.0 | 2.5 | 0.1 |

另提供 3 个快捷按钮：**俯视**（elev=85）、**斜视**（elev=58）、**侧视**（elev=20）。

### 3.5 分组 5：样式

| 参数 | 控件 | 默认 | 说明 |
| :--- | :--- | :--- | :--- |
| `line_color` | `<input type="color">` | `#FFD700` | 边界线颜色 |
| `line_width` | 滑块 0.5 – 6.0 | 2.2 | 边界线宽 |
| `show_labels` | 开关 | 开 | 显示质心标注 |
| `show_centroids` | 开关 | 开 | 显示质心圆点 |
| `label_fontsize` | 滑块 8 – 20 | 11 | 标注字号 |
| `nodata_color` | `<input type="color">` | `#BFBFBF` | NoData 区域填充色 |

### 3.6 底部按钮

- **[应用]**：调 `/api/render`，用当前参数刷新 3D 视图
- **[重置]**：恢复后端返回的默认参数（不是页面初始值，是上传后返回的 `defaults`）

## 4. SHP 字段勾选功能（新增）

### 4.1 后端：`/api/upload` 返回字段元数据

在 `/api/upload` 的返回体中，新增 `fields` 数组：

```json
{
  "session_id": "abc123...",
  "figure": { ... },
  "meta": { ... },
  "fields": [
    {
      "name": "name",
      "dtype": "object",
      "n_unique": 5,
      "n_missing": 0,
      "samples": ["A区", "B区", "C区", "D区", "E区"]
    },
    {
      "name": "code",
      "dtype": "int64",
      "n_unique": 5,
      "n_missing": 0,
      "samples": [1, 2, 3, 4, 5]
    },
    {
      "name": "area_km2",
      "dtype": "float64",
      "n_unique": 5,
      "n_missing": 0,
      "samples": [0.52, 0.31, 0.87, 0.44, 0.63]
    }
  ],
  "default_display_fields": ["name"]
}
```

字段元数据规则：
- 遍历 SHP 所有非几何字段
- `dtype`：用 `str(series.dtype)` 的值
- `n_unique`：唯一值数量
- `n_missing`：NULL 数量
- `samples`：最多取 5 个非 NULL 的唯一值示例，值太长时截断到 30 字符
- `default_display_fields`：自动探测（`name`/`名称`/`隐患点`/`灾害点` 等），找不到就用第一个字符串型字段；如果一个都没有，返回空数组

### 4.2 前端：字段勾选区

在左侧“2. 数据处理”分组里，新增一个子区域 **“SHP 字段展示”**：

```
┌──────────────────────────────────┐
│ SHP 字段展示                     │
│                                  │
│ ☑ name        示例: A区, B区...  │
│ ☑ code        示例: 1, 2, 3...   │
│ ☐ area_km2    示例: 0.52, 0.31...│
│ ☐ notes       示例: 滑坡, 崩塌... │
│                                  │
│ 已选: 2 个字段                   │
└──────────────────────────────────┘
```

规则：
- 每个字段一行，左侧复选框，中间字段名，右侧灰色小字显示前 3 个示例值
- 勾选状态变化时，**不立即刷新** 3D 视图，等用户点“应用”才刷新
- 如果 SHP 没有任何可勾选字段，显示提示“该 SHP 无可展示的属性字段，将只显示序号”
- 至少勾选 0 个，允许全部不勾（此时只显示序号）
- 勾选数量超过 3 个时，在质心标注里改为换行显示；超过 5 个时提示“标注字段过多，建议不超过 3 个”

### 4.3 标注文本生成规则

后端根据 `display_fields` 生成每个区的标注文本：

- **0 个字段**：`"{序号}"`，例如 `"1"`
- **1–3 个字段**：`"{序号}. {值1} / {值2} / {值3}"`，例如 `"1. A区 / 1 / 0.52"`
- **4 个及以上字段**：`"{序号}. {值1}\n{值2}\n{值3}..."`，换行显示

字段值缺失（NULL）时显示 `"—"`。

### 4.4 悬停信息（hovertext）

无论勾选几个字段，**hovertext 始终显示所有字段**，格式：

```
序号: 1
name: A区
code: 1
area_km2: 0.52
notes: 滑坡
```

这样可以满足 v1 §Q7 的“点击某个区显示属性”需求。

### 4.5 `/api/render` 参数新增

在 v1 §4.7 的参数体里，新增 `display_fields` 字段：

```json
{
  "session_id": "abc123...",
  "params": {
    "...": "...",
    "display_fields": ["name", "code"]
  }
}
```

后端根据 `display_fields` 重新生成标注文本和 hovertext。

## 5. 结果下载区（替换 v1 §5.1 下载区描述）

位于右侧 3D 视图下方，固定高度约 100px，横向排列：

```
┌──────────────────────────────────────────────────────────────┐
│ 分辨率: [1920×1440 ▼]   DPI: [300 ▼]   [下载 PNG]  [下载 HTML] │
└──────────────────────────────────────────────────────────────┘
```

### 5.1 分辨率下拉选项

- 1280×960（屏幕）
- 1920×1440（报告）— 默认
- 2560×1920（高清）
- 3840×2880（出版）
- 自定义 → 显示宽 × 高输入框

### 5.2 DPI 下拉选项

72 / 150 / 300（默认）/ 600

### 5.3 下载按钮

- **[下载 PNG]**：调 `/api/download`，用当前参数 + 分辨率 + DPI 生成 PNG
- **[下载 HTML]**：调 `/api/download_html`（新增接口），返回交互式 HTML 文件，用户可离线打开、自己旋转

### 5.4 新增接口 `/api/download_html`

请求体同 `/api/download`，返回 `text/html` 流。内容为：

```html
<!DOCTYPE html>
<html>
<head><meta charset="utf-8"><title>{title}</title>
<script src="https://cdn.plot.ly/plotly-2.32.0.min.js"></script>
</head>
<body style="margin:0">
<div id="fig" style="width:100vw;height:100vh"></div>
<script>
var fig = {Plotly figure JSON};
Plotly.newPlot('fig', fig.data, fig.layout, {responsive: true});
</script>
</body>
</html>
```

## 7. 修改清单（给 Claude CLI 的执行摘要）

按以下顺序修改现有代码：

### 7.1 后端改动

1. **`processing.py`**：
   - `load_and_process()` 返回体新增 `fields`、`default_display_fields`、`diagnostics`
   - 新增函数 `extract_field_metadata(gdf)` 提取字段元数据
   - 新增函数 `build_label_text(row, seq, display_fields)` 生成标注文本
   - `build_hovertext(row, seq)` 生成 hovertext（始终包含全部字段）

2. **`rendering.py`**：
   - `build_figure()` 接收 `display_fields` 参数
   - 质心标注 trace 的 `text` 根据 `display_fields` 动态生成
   - 质心标注 trace 的 `hovertext` 始终包含全部字段

3. **`main.py`**：
   - 新增 `POST /api/download_html` 路由
   - `/api/upload` 返回体新增 `fields`、`default_display_fields`、`diagnostics`
   - `/api/render` 参数支持 `display_fields`

### 7.2 前端改动（重写 `index.html` + `app.js` + `style.css`）

1. **布局**：
   - 用 CSS Grid 实现左右分栏
   - 左侧：上传 → 数据处理 → 制图参数 → 底部按钮
   - 右侧：3D 视图 + 下载区

2. **参数面板**：
   - 用 `<details>` 分组：标题 / 地形 / 光照 / 视角 / 样式
   - 每个滑块旁边显示实时数值
   - 快捷视角按钮（俯视/斜视/侧视）

3. **字段勾选**：
   - 上传成功后，从 `fields` 数组动态渲染复选框列表
   - 默认勾选 `default_display_fields` 里的字段
   - 勾选状态同步到 `currentParams.display_fields`

4. **下载区**：
   - 分辨率下拉 + DPI 下拉 + 两个下载按钮
   - 下载 PNG 调 `/api/download`，下载 HTML 调 `/api/download_html`

5. **状态管理**：
   - `currentParams` 对象统一管理所有参数
   - 参数改变时只更新 `currentParams`，点“应用”才调 `/api/render`
   - “重置”按钮把 `currentParams` 恢复到上传时返回的默认值

## 9. 不做的事（在 v1 §10 基础上新增）
